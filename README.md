# مشروع تصنيف صور القطط والكلاب باستخدام الذكاء الاصطناعي (Cat and Dog Image Classification)

هذا المستودع يضم مشروعاً لتعلم الآلة والتعميق العميق (Deep Learning) باستخدام لغة بايثون ومكتبة TensorFlow، والمخصص للتمييز وتصنيف الصور بين القطط والكلاب بدقة عالية.


## ?? نبذة عن المشروع
يهدف هذا المشروع إلى بناء وتدريب نموذج شبكات عصبية تلافيفية (CNN) أو استخدام تقنيات النقل المعرفي (Transfer Learning مثل MobileNetV2) قادرة على تحليل الصور وتصنيفها بشكل آلي لتمييز ما إذا كانت الصورة تحتوي على قطة أو كلب.

## ?? المميزات الرئيسية
- **تجهيز البيانات:** تنظيم ومعالجة مجموعات الصور وتقسيمها إلى مجلدات للتدريب (Train) والتحقق (Validation).

- **تدريب النموذج:** بناء وتدريب نموذج ذكاء اصطناعي باستخدام TensorFlow و Keras.
- **التقييم والتحليل:** قياس دقة الأداء وتقييم نتائج النموذج على صور جديدة.
